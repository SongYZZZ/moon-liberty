# MoonLiberty 0.4.4 保守补齐与复查（2026-10-29）

## 结论

本轮针对实际缺陷、可用性和有限格式缺口补齐，九个命令、六份公开接口及现有求值维度保持一致。完成本地完整回归、真实库独立核对和文件异常路径检查。未引入新依赖。完整 Liberty 2017.06 仍未完成，本记录不代表官方终审通过；上一版事实见 [0.4.3 报告](history/FINAL_REVIEW_0_4_3.md)。九项工程要求见 [验收核对](ACCEPTANCE.md)。

## 已复现并修复

1. 每个 ff/latch/statetable 重建同一单元的状态名表，导致重复扫描；4096 个 ff 的约 190 KB 合法输入在旧版超过 30 秒未完成。现在每个单元建立一次环境，保留前向引用、同级状态可见性和不同/嵌套单元隔离。本机压力脚本约 351.31 ms，包含进程和 IO，不作普遍速度保证。
2. 用户声明使用线性查找；同名属性有多个合法父组时，一次越作用域使用被重复报告。改用名称、父组分开的两层索引，保持首个定义及重复定义报错。64 个父作用域反例现在只报告一次，不再放大该诊断。
3. 已声明简单属性 rank:... 可以改写成 rank(1.5); 绕开类型检查。现在返回 DefinedAttributeForm；未声明的厂商复杂属性仍可原样保留。
4. 总线声明给出宽度、单端点和方向时，遗漏另一端点使越界成员漏报。现在对该明确组合推导边界；负成员和推导出的负端点均拒绝。其余默认组合、自定义命名和向量展开仍开放。依据 Reference Bus Groups 1-76—1-77 及 type 属性 2-123—2-125，见[标准契约](STANDARD_CONFORMANCE.md)。
5. 非负 rise_transition/fall_transition 表可被外推成负转换时间，旧 SI 查询仍返回成功。现在返回 NegativeTransition；合法负传播延迟、通用查表和零转换时间仍允许。
