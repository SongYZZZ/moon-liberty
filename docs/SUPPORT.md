# 范围和限制

标准基线为 Liberty 2017.06，完整格式兼容的最终目标与当前缺口见 [标准契约](STANDARD_CONFORMANCE.md)。本页的求值限制不删减最终格式目标。0.2.0 当前完整符合性为 false。

| 能力 | 当前支持 | 明确边界 |
| --- | --- | --- |
| 通用语法 | 注释、续行、引号、属性、复杂属性、分组、未知扩展 | 单个具名 library 根；通过显式 source map 展开 include；不解压 .gz |
| 文本往返 | 稳定缩进，保留未知属性和分组，核对写出前后 AST | 丢弃注释与排版；不保留字节级原文 |
| 领域模型 | library / cell / pin / timing / lu_table_template | 不展开 bus / bundle；泛型 AST 仍保留这些分组 |
| 单位 | 时间、容量、可选电压的显式 SI 比例 | 缺失单位可检查，SI 查询会拒绝；不猜默认值 |
| 检查 | 重复、数值、方向、引脚及逻辑引用、网格、时序类型字段 | 不是全部 Liberty 厂商规则的标准认证 |
| 表格 | 六类时序表的标量、一维、二维模型与插值 | 三维报告 UnsupportedDimension；不求值 CCS/ECSM/LVF |
| SI 查询 | cell_rise / cell_fall / rise_transition / fall_transition 组合弧 | 不求值 setup/hold 等约束表；不做路径 STA |
| 条件弧 | --when 显式匹配原条件字符串；歧义拒绝 | 不自动推导条件蕴含或输入波形 |
| 布尔函数 | !、~、后缀 '、与、或、异或、隐式与、常量和括号 | 不是完整 Verilog；真值表默认 12 输入、硬上限 16 |
| 差异 | 结构、数值写法、支持的布尔运算符写法归一；未知字段可见 | 不是 SAT/逻辑等价、物理等价或时序回归阈值判定 |
| 单元提取 | 指定 cell 和所有原有库级上下文 | 不递归裁剪模板、不是网表或布局提取 |
| 后端 | 核心 native / JS / Wasm GC，CLI native | 文件命令依赖官方 async 原生 IO |
| 文件输出 | 独占临时文件、同步文件后改名、默认不覆盖 | 不声明目录 fsync 或突然断电时的持久性保证 |

范围策略：不支持的求值请求应显式拒绝；未知语法字段可以保留，但保留不等于理解或验证。lint 的零错误仅代表通过已实现规则。normalize/extract 是结构操作，调用者应另外 lint 输出。

## 默认资源上限

CLI 只读取普通 UTF-8 文件，输入不超过 16 MiB；核心文本上限为 16,777,216 个 UTF-16 代码单元。核心最多 2,000,000 个 token、单 token 1,048,576 个代码单元、128 层分组、1,000,000 个 AST 节点。表格单轴最多 10,000 点、最多 1,000,000 个值。

CLI 输出最多 64 MiB。差异最多 200,000 个索引项，默认展示 10,000 个变化，可调至 100,000；单字段预览 1024 个字符，截断标记及完整变化计数会保留。它是有界内存解析器，不是流式超大工艺库解析器。真实样本 1,720,231 字节；未验证所有商业工艺库。

坐标必须有限且非负；默认越界失败。clamp/extrapolate 只能显式选择，结果标记该行为；只有单点轴时不能推导外推斜率。查询前会运行领域检查；批量热路径可自行加载并选择 Table 后调用 lookup_table，不能把微基准时间当作整个 CLI 查询耗时。
